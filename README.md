This script (src/js/pixabay-api.js) queries the Pixabay API to search and page through images, parses responses, handles errors/status, and returns formatted image data for the app's UI.

Цей скрипт (src/js/pixabay-api.js) робить запити до API Pixabay для пошуку і пагінації зображень, обробляє відповіді й помилки та повертає підготовлені дані для відображення в інтерфейсі.
